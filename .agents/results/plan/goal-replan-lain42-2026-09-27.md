# Lain42 全平台 Agent：活动 Goal 重规划（2026-09-27）

本计划按用户能完成的任务定义成功，并把 DSH 明确为目标对话运行时；迁移采用可回滚的小步切换，先以现有实现建立验收基线，再尽早验证 DSH 承载真实聊天与工具闭环。当前活动 Goal 已包含网站模型、资料闭环、账号隔离、本人设备、客户端计算和积分/知识空间；本次重排细化执行顺序，不另建冲突的平行 Goal。架构边界见[平台架构建议](../architecture/architecture-recommendation-lain42-platform.md)，机器任务清单见[计划 JSON](goal-replan-lain42-2026-09-27.json)。活动 Goal 继续进行中；本文不是线上完成声明。

## 目标

把 Lain42 做成打开网页或手机就能使用的 Agent：默认使用网站模型；搜索、URL、GitHub OAuth 和用户确认的附件能把真实资料交给模型并得到有来源的回答；免登录用户有受限试用，登录用户的数据和凭据严格隔离；客户端承担合适的解析与代码展示；只有用户明确授权后才在其本人设备运行 CLI/MCP；积分、模型用量和私有知识空间可审计、可对账。

成功由用户结果决定。DSH 是目标对话运行时，不是等待所有产品功能做完才评估的远期实验：先用现有链路做正确性基线，随后立即在受保护入口接入 DSH，再按同一套契约逐步扩大流量。只有在身份隔离、真实任务、错误恢复、费用一致性和资源门槛都通过后才把它设为默认。迁移期间每轮只能有一个执行者，不双推理、不双扣费、不重复运行有副作用的工具。

## 六项完成门

1. **打开即用**：桌面和手机的 Web/PWA 可用网站模型；匿名试用有服务端额度与反滥用限制，不获得私人凭据、设备或持久私有数据。设备离线不影响普通聊天。
2. **真正干活**：搜索、公开 URL、GitHub OAuth 和附件结果进入当前轮模型；回答当前问题并给出可打开来源。工具完成通知不算答案。
3. **授权隔离**：网站 OAuth 与设备本机 gh 独立；撤销立即生效；令牌不进入模型或普通日志；会话、文件、设备、知识、积分和用量不跨账号。
4. **本人设备按需运行**：只有用户选中并授权自己的设备后才运行 CLI/MCP；设备、目录、权限、写操作确认和撤销可见。A7A 永远是站点所有者的私人设备。
5. **客户端计算**：代码高亮、文件预览和有界解析优先在浏览器/Worker；用户确认实际发送内容。按实测选择 JS、Worker 或 WASM，不绕过 CORS 或系统权限。
6. **商业运营**：充值、消费、退款、管理员发放和模型用量形成幂等可审计账本；普通用户 5 GB、会员 20 GB 私有知识空间由服务端强制配额并正确回收。

全目标完成须同时具备 Actions、真实浏览器、双账号隔离、手机主要流程、设备断线、费用/配额幂等及回滚证据。编译成功、OAuth 卡片显示连接或工具显示完成都不单独算通过。

## 执行顺序

| 阶段 | 交付 | 放行标准 |
|---|---|---|
| G0 可信对话基线 | 修复错答、串题、失败回合污染；区分模型限流、站点容量和设备离线 | 真实模型多轮、短追问、纠正和错误恢复回归通过；普通聊天不依赖设备 |
| G1 身份与 turn 契约 | 服务端推导身份、受限匿名会话、turnId/requestId、事件顺序、取消/续读和用量关联 | 双账号跨读拒绝；匿名不能访问私人资源；请求幂等；新旧运行时契约一致 |
| G2 DSH 对话核心与资料闭环 | 受保护入口接入 DSH；New API 保留模型、授权、积分和用量；逐项迁移聊天、搜索、URL、GitHub OAuth | DSH 与基线使用同一模型和工具适配器；每轮只有一次推理/计费；真实回答、来源、工具记录和恢复通过后渐进设为默认 |
| G3 附件、代码与手机 | 客户端预览/确认/解析，Rust/JSON/Markdown 高亮，窄屏操作 | 合成附件被准确引用；未确认不上传；失败可恢复且不重复计费 |
| G4 积分与知识 | 可审计账本、管理员发放、usage 对账、私有 OSS 和 5/20 GB 配额 | 重复交易幂等；并发上传不超额；跨账号不可读；删除释放配额 |
| G5 本人设备工具 | 用户本人设备上的 CLI/MCP，能力白名单、目录限制、写入确认、撤销 | 仅 owner 可执行；设备离线不影响 G0–G4；不依赖 A7A |
| G6 跨平台发布与运营 | Web/PWA、Tauri、Android 入口共享同一账户和对话体验；监控、回滚与资源门禁 | 窄屏关键任务通过；部署可观测可回滚；DSH 资源成本在既定门槛内 |

G0 与 G1 先形成稳定基线和服务契约。G2 随后尽早接入 DSH，先做站点所有者受保护试用，再逐个迁移对话、搜索、URL 和 OAuth 工具；任一子流程不通过就保留对应基线路径，禁止双跑。身份隔离是私人 OAuth、文件、知识和设备开放前置。G3/G4 可以在 DSH 工具协议稳定后并行推进；G5 依赖身份、授权和审计。跨平台客户端最后复用统一服务，不复制业务规则。

## 工作包与接口原则

- 先复现普通聊天的错答、短输入串题、失败轮污染、429/503 和容量拒绝。失败说明真实类别，不用硬编码答案冒充模型。
- 浏览器不提交可信 userId、workspaceId、cwd 或模型密钥。每轮有 requestId、turnId、runId 与单调事件序号；事件可续读，副作用不自动重放。
- 搜索、WebFetch、GitHub OAuth 和附件必须先取得真实资料，再交给同轮模型继续回答。GitHub 网站 OAuth 不依赖本机 gh。
- 附件先在客户端展示解析范围、片段和大小，用户确认后才发送；大文件可取消且有资源上限。
- 积分复用现有钱包/权益真值，禁止无来源直接改余额。知识 OSS 对象私有，服务端事务维护配额预留、删除和恢复。
- DSH 只接受 Lain42 服务端的内网请求和短时、限定受众与能力的身份断言；不能公开 DSH Host/Remote 管理入口或通用 shell/filesystem preset。新旧对话运行时共享工具契约、账单归属和回归集，但每一轮只能选其一执行。

## 不做

本轮不共享 A7A、不做公共算力出租、自动代发邮件/QQ/微信/Telegram、多 Agent 委派、全站 Rust/WASM 重写或重型 LLVM 包。ZeroStack 只保留为未来可选 coding worker。

## 当前证据

- New API 是线上 Agent 基线；已验证 DSH PeerScope 不等同网站用户授权，通用 Web preset 含 shell/filesystem 能力，不能直接公网开放。DSH 仍须由 Lain42 身份适配层隔离，不可直接暴露管理端点。
- New API `6dd9f7a` 已通过 Actions CI `36290058878` 与 Linux Agent 构建 `36290058901` 并部署为 `agent-flat-6dd9f7a`。真实浏览器已核验：普通聊天不受 A7A 离线影响；GitHub OAuth 查询从实际仓库资料生成回答；公开 URL 会带正文和来源进入模型；手动网页搜索结果可加入当前消息并得到来源回答；Rust、TOML、Shell 代码块有客户端高亮及复制/下载入口。
- 提交 `d98436c` 的 CI `36292624880` 和 Linux Agent 构建 `36292624854` 均通过，并已部署为 `agent-flat-d98436c`。真实网页搜索验收发现：完整中文指令被直接当作查询词，搜索到“请”的词典页面；模型还引用了不在搜索结果中的 Rust 页面。该闭环不通过验收。
- 修复提交 `8ade936` 从明确搜索请求中提取主题、丢弃与主题无关的结果，并拒绝展示模型生成但检索结果未提供的链接；新增对应回归用例。CI `36294259846` 与 Linux Agent 构建 `36294259843` 均已通过，构建报告前端 88 个测试文件、589 项测试通过。修复版尚未部署：本机到产物存储的连接被拒绝，浏览器的产物下载入口又被客户端拦截；因此没有修复后的生产浏览器验收证据。
- 文件上传实机验收暂受当前 Chrome 扩展“允许访问文件 URL”权限关闭所阻；不能通过自动化擅自扩大浏览器扩展权限。双账号隔离、Android 窄屏、积分账本和 5/20 GB 知识配额仍未完成端到端验收。活动 Goal 继续进行中。

## 固定约束

- 项目构建、自动化测试和打包只在 GitHub Actions；本机不编译或运行项目测试。
- Actions 未通过不部署；部署后核对服务版本和浏览器流程。
- 不重启或共享 A7A，不读取浏览器 Cookies，不把 OAuth/API key 交给模型。
- 完成记录包含代码版本、Actions run、部署版本、浏览器结果和限制；未部署或未实测的功能明确标注。
